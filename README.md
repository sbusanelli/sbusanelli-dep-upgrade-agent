# Dependency Upgrade Agent

Automated dependency upgrade tool for GitHub repositories. 

## Features

- 🚀 Automated dependency updates
- 📦 Multi-language support (Python, JavaScript, Go, Rust)
- 🔍 Smart change detection
- 📝 Automated PR creation

## Supported

pip, npm, Go modules, Cargo, Bundler, Maven, Gradle

## Usage

```bash
pip install sbusanelli-dep-upgrade-agent
```
